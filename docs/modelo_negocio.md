# Modelo de negocio — HUÁSCAR 3D (Lean Canvas)

| Bloque | Contenido |
|---|---|
| **Problema** | La historia del Perú se enseña de forma poco interactiva. Hay pocos videojuegos peruanos sobre hechos reales. Los juegos navales comerciales requieren instalación y equipos potentes. |
| **Segmentos de clientes** | Estudiantes de 10 a 17 años; colegios (curso de Historia / Ciencias Sociales); aficionados a juegos de historia y estrategia; peruanos en el extranjero. |
| **Propuesta de valor** | Aprender la Guerra del Pacífico jugando: batallas reales en 3D, datos históricos, modo cooperativo para el aula y voz en español, todo en el navegador y sin instalación. |
| **Solución** | Juego web gratuito con 2 batallas + versión educativa con guía docente y estadísticas por alumno. |
| **Canales** | GitHub Pages / itch.io; clips en TikTok y YouTube; ferias escolares; alianzas con colegios y museos navales. |
| **Flujos de ingreso** | *Freemium*: 2 batallas gratis. Licencia institucional anual para colegios (más batallas, panel docente). Paquetes de batallas (Punta Gruesa, Arica, Callao). Donaciones. Arte digital pixel art. |
| **Estructura de costos** | Tiempo de desarrollo; dominio y hosting (gratis al inicio con GitHub Pages); música con licencia; difusión. |
| **Métricas clave** | Usuarios activos, partidas completadas, tiempo medio de juego, colegios con licencia, conversión de gratuito a licencia. |
| **Ventaja diferencial** | Contenido histórico peruano tratado con respeto por ambos bandos + 3D en navegador + cooperativo local + reconocimiento de voz. |

## Proyección simple (supuestos por validar)
- Año 1: publicación gratuita, meta de 5 000 partidas y 3 colegios piloto sin costo para recoger retroalimentación.
- Año 2: licencia institucional (precio por definir con los pilotos) y primer paquete de batallas.
